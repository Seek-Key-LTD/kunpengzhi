# 双约记播客脚本：迭代方法论

## 核心思想

文稿迭代 = 矩阵乘法。每一层是一个"算子"，只解决一个问题，层层渗透。

```
最终脚本 = Layer5 · Layer4 · Layer3 · Layer2 · Layer1 · 原文
```

---

## Layer 1: 内容提取算子 (Content Extractor)

**输入**: 原文 markdown
**输出**: 结构化提纲

**规则**:
- 提取核心论点（骨架）
- 提取支撑数据（血肉）
- 提取隐喻/段子（皮肤）
- 标注哪些是"必讲"、哪些是"选讲"、哪些是"可删"

**示例**:
```
骨架: 冰箱空调隐喻（封闭系统 vs 开放系统）
血肉: 1877年专利法、1320亿金马克、3B铁路
皮肤: 国足10:1、波西米亚狂想曲
```

---

## Layer 2: 对话结构算子 (Dialogue Structurer)

**输入**: 结构化提纲
**输出**: 对话框架

**规则**:
- 每集必须有 **Warm-up + Opening + Main Body + Closing** 四段结构
- **Warm-up（暖场）**: 青衣主持，30秒内完成
  - 自我介绍（我是谁）
  - 介绍搭档（他是谁）
  - 今天摆什么（主题预告）
- **Opening（开场）**: 峨眉切入，1分钟内完成
  - 缘起：为什么要做这个播客
  - 受众：这个节目适合谁听
  - 书的价值：《双约记》牛逼在什么地方
  - 出版信息：KDP已上线，国内发京东/国图等
- **Main Body（正文）**: 峨眉讲骨架，青衣追问
  - 每个论点有"峨眉陈述 → 青衣追问 → 峨眉深化"的三拍节奏
  - 禁止：连续3句以上同一人独白
- **Closing（结尾）**: 青衣收束
  - 本集总结（一句话回顾核心观点）
  - 下集预告（制造追剧感）
  - 引导关注（订阅/评价）

**示例（Warm-up + Opening）**:
```
[青衣]
大家好，我是青衣，《财经周刊》调查记者。旁边这位是峨眉师傅，川大历史学副教授，研究冷战史的。

[峨眉]
安逸。今天摆个硬核的龙门阵。

[青衣]
峨眉师傅，先给新朋友说说，我们为啥子要搞这个播客？

[峨眉]
因为这本书，《双约记》，写得太硬核了，普通人读不进去。但它讲的东西，跟我们每个人都有关——从冰箱空调到雅尔塔，从费迪南的胡子到麦克斯韦的妖。

[青衣]
这本书已经上了亚马逊KDP，国内也会发京东、国图这些渠道。今天这一集，我们先从序言摆起。

[峨眉]
要得，那就从你家厨房摆起。
```

**示例（Main Body）**:
```
[峨眉] 冰箱是封闭系统...
[青衣] 那德国人咋个办？
[峨眉] 德国人没得外机...
```

**示例（Closing）**:
```
[青衣]
今天摆了冰箱空调的隐喻，核心就是一句话：过去五百年的资本主义历史，就是一部找外机位的历史。

[峨眉]
下一章我们摆1936到1941，旧秩序的崩塌。你晓得柏林奥运会不？纳粹搞了一场盛宴，被一个黑人运动员的四枚金牌打脸了。

[青衣]
要得，下回分解。喜欢的朋友记得订阅，我们下期再见。
```

## Layer 3: 四川方言算子 (Sichuan Dialect Localizer)

**输入**: 对话框架
**输出**: 方言化对话

**规则**:
- 句式转换:
  - "是什么" → "是啥子"
  - "怎么了" → "咋个了"
  - "没有" → "没得"
  - "对吗" → "对不对嘛"
  - "是的" → "要得"
- 语气词添加:
  - 句首: "诶"、"哎"、"嚯"
  - 句中: "嘛"、"撒"、"哈"
  - 句尾: "咯"、"噻"、"嘞"
- 方言词汇替换:
  - "厉害" → "凶"
  - "舒服" → "巴适"
  - "可以" → "要得"
  - "讨厌" → "烦"
  - "傻" → "瓜"

**示例**:
```
Before: 这个比喻很有意思
After: 这个比喻有点意思嘛
```

## Layer 4: 文学润色算子 (Literary Polisher)

**输入**: 方言化对话
**输出**: 文学性增强版

**适用场景**: 峨眉的宏大叙事段落

**规则**:
- 排比增强:
  - Before: "过去五百年的历史..."
  - After: "五百年，五百年的风雨，五百年的血与火..."
- 比喻深化:
  - Before: "德国没得外机"
  - After: "德国人困在冰箱里，外面的世界再热闹，跟他们没得关系"
- 引用嵌入:
  - 适当引用古诗词、名人名言
  - 但必须用四川话读出来不违和
- 节奏控制:
  - 长句用于宏大叙事
  - 短句用于强调和转折

**示例**:
```
Before: 过去五百年的资本主义历史，就是一部找外机位的历史。
After: 五百年，五百年啊，资本主义这部大戏，演的就是一个字——找。找啥子？找外机位。把自家的烂摊子排到别人屋头去，自己屋头才能岁月静好。
```

---

## Layer 5: 俗语强化算子 (Colloquial Intensifier)

**输入**: 文学性增强版
**输出**: 最终脚本

**适用场景**: 青衣的追问段落、两人交锋段落

**规则**:
- 四川俚语嵌入:
  - "龟儿子"（用于强调或调侃）
  - "瓜娃子"（用于批评）
  - "扯把子"（用于质疑）
  - "洗白"（用于描述失败）
  - "锤子"（用于否定）
- 网络用语适度混搭:
  - "RNM退钱"（用于描述愤怒）
  - "这波在大气层"（用于描述高明）
  - "我直接好家伙"（用于表示震惊）
- 脏话节制:
  - 可以用"龟儿子"，但不能用真正的脏话
  - 保持"接地气但不低俗"的底线

**示例**:
```
Before: 这个逻辑不对
After: 等一下，你这个逻辑不对哈，数据呢？
```

## Layer 6: 电台包装算子 (Radio Show Wrapper)

**输入**: 最终脚本
**输出**: 电台化脚本

**核心设定**:
- 节目名: 《峨眉夜话》或《冷战茶馆》
- 频道: 成都交通广播 FM103.7（虚构）
- 时段: 午夜 00:00-01:00
- 风格: 深夜电台 + 茶馆龙门阵

**开场模板**:
```
[电台音效: 收音机调频声 + 轻柔BGM淡入]

[电台DJ声]
听众朋友们，晚上好。这里是成都交通广播 FM103.7，现在是午夜零点。您正在收听的是《峨眉夜话》，我是主持人小青。

[音乐渐弱]

[青衣]
大家好，我是青衣。旁边这位是峨眉师傅。

[峨眉]
安逸。这么晚了还在听节目，怕是睡不着嘛。

[青衣]
睡不着正好，今天我们摆点硬核的。
```

**结尾模板**:
```
[青衣]
今天就摆到这里。喜欢的朋友记得订阅，我们下期再见。

[峨眉]
安逸。晚安。

[电台音效: BGM渐强 + 收音机调频声]
[电台DJ声]
感谢收听《峨眉夜话》。下周同一时间，我们继续摆龙门阵。晚安，好梦。

[音乐淡出]
```

**音效清单**:
- 收音机调频声（开头/结尾）
- 轻柔BGM（古琴/竹笛/钢琴，营造深夜氛围）
- 环境音（茶馆嘈杂声、雨声、远处钟声）
- 转场音效（章节切换时）

**Addons（加戏模块）**:

定义：在正文中随机插入的"电台真实感"元素，打破第四面墙，让听众觉得这是真的在听广播。

**Addon 类型**:

1. **交通路况** (Traffic Update)
   - 插入时机：正文中段，制造"广播感"
   - 示例：
   ```
   [电台音效: 提示音]
   [青衣]
   峨眉老师，你稍等一下。天府机场东路发生了轿车追尾，我们在这里提醒广大司机师傅：晚上了少出来跑，注意身体，多听听像我们这样有分量的节目，听听厚重历史，听听厚重逻辑。
   [音效结束]
   ```

2. **天气预报** (Weather Report)
   - 插入时机：节目开头或结尾
   - 示例：
   ```
   [电台音效]
   [青衣]
   插播一条天气：成都今晚多云转阴，气温18到22度，适合熬夜听节目。
   ```

3. **听众互动** (Listener Interaction)
   - 插入时机：节目后半段
   - 示例：
   ```
   [青衣]
   刚才有听众发短信问，峨眉老师，你那个冰箱空调的比喻，能不能用在A股上？
   [峨眉]
   嘿，这个问题问得好。A股嘛，就是个冰箱，热量在里面转圈圈...
   ```

4. **广告植入** (Fake Ad)
   - 插入时机：节目中段，制造黑色幽默
   - 示例：
   ```
   [青衣]
   好，我们进一段广告。"峨眉山茶叶，喝一口，想两天。"——好了，广告完了，继续。
   ```

5. **时间提示** (Time Check)
   - 插入时机：每隔5-8分钟
   - 示例：
   ```
   [青衣]
   现在是凌晨十二点二十三分，我们聊了快半小时了。
   ```

**Addon 使用规则**:
- 每集插入2-3个，不能太多（会打断节奏）
- 交通路况最常用，制造"直播感"
- 天气预报放在开头或结尾
- 听众互动放在后半段
- 广告植入用于黑色幽默
- 时间提示用于控制节奏

**节奏控制**:
- 开场: 30秒（电台包装 + 暖场）
- 正文: 15-18分钟
- 结尾: 30秒（总结 + 电台收尾）
- 总时长: 16-19分钟

## 迭代流程

```
原文 → [L1: 提取] → 提纲 → [L2: 结构] → 框架 → [L3: 方言] → 方言版
                                                          ↓
                                              [L4: 文学] → 文学版
                                                          ↓
                                              [L5: 俗语] → 最终脚本
```

**关键原则**:
1. 每层只做一件事，不混着来
2. 文学和俗语是两个独立的算子，不能同时应用
3. 峨眉的段落重点用L4（文学），青衣的段落重点用L5（俗语）
4. 最终脚本必须通过"朗读测试"——用四川话读出来，要像茶馆里摆龙门阵

## 质量检查清单

- [ ] 骨架完整：核心论点是否都保留了？
- [ ] 血肉充实：数据和细节是否够硬？
- [ ] 皮肤到位：隐喻和段子是否有趣？
- [ ] 对话自然：是否像真人对话而不是念稿？
- [ ] 方言地道：四川人听了会不会笑？
- [ ] 文学够味：学术底色是否保留？
- [ ] 俗语得当：是否接地气但不低俗？
- [ ] 节奏舒服：是否有张有弛？
