## 出现节点

### 高置信度

1. **撒马尔罕 = "夏"之都会**
   - 原文: "'撒马尔罕'（Samarkand）的前缀'Sam'，与'夏'的远古音'Sa'高度吻合"
   - 论点: 撒马尔罕是大禹后裔西迁建立的"夏朝都城"
   - 时间: 大禹前2070年→前8世纪在撒马尔罕稳定建都
   - 来源: 牧兰记（中）地质篇

2. **金桃 = 撒马尔罕特产**
   - 原文: Samarkand = 金桃产地
   - 论点: "Sam" = 金（与Altan同源）
   - 来源: etymology/AURUM.md

3. **祭司王约翰 = 耶律大石**
   - 原文: "耶律大石以少胜多，大破十万穆斯林联军，震动了整个欧洲（也就是传说中的'祭司王约翰'的原型）"
   - 论点: 祭司王约翰是欧洲人对契丹/中亚基督教王国的误读
   - 来源: 牧人记（下）历史篇

4. **耶律大石停战 = 草原逻辑**
   - 原文: "打完之后呢？耶律大石没有乘胜追击去攻占巴格达...他停下来了"
   - 论点: 草原帝国的战争逻辑是"生存和尊严"而非"无休止的贪婪"
   - 来源: 牧人记（下）历史篇

5. **所罗门穹顶 = 金链悬天**
   - 原文: "'所罗门啊，我已超越了你。'...这个穹顶仿佛没有基座，它像是被一条金链子从天堂悬挂下来的"
   - 论点: 圣索菲亚大教堂的穹顶被比作"超越所罗门"
   - 来源: 牧人记（下）历史篇

6. **大卫王的语言 = 希伯来语复活**
   - 原文: "《侏罗纪公园》...斯皮尔伯格潜意识里听见的...是1948年特拉维夫街头，那个古老民族用大卫王的语言宣告建国的号角"
   - 论点: 大卫王语言=希伯来语，死而复活的民族语言
   - 来源: 牧人记（下）历史篇

### 中置信度

7. **示巴女王 = 南方智慧国**
   - 原文: （待补充，示巴与撒马尔罕/阿拉伯南部的关联）
   - 论点: 示巴（Sheba）可能是撒马尔罕的另一个历史名称
   - 来源: 牧兰记

## 核心论证：撒马尔罕 = "夏"的西端锚点

### 撒马尔罕三重身份
```
1. 夏朝都城（Samarkand = "夏"之都）
    ↓
2. 金桃产地（Sam = 金/Altan = 黄金）
    ↓
3. 祭司王约翰（耶律大石 = 东方基督教王国）
```

### 音变链
```
Samarkand（撒马尔罕）
    ↓
Sam（夏/Sa音）+ Arkand（罕/都城）
    ↓
夏（Xia）= 夏朝
    ↓
Sam = 金（与Altan/Aurum同源）
    ↓
金桃 = 撒马尔罕的黄金特产
```

### 梭伦 = 撒马尔罕立法者？
- Solon（梭伦，希腊立法者）与Solomon（所罗门）词根相近
- 可能反映希腊立法传统与闪族王权传统的融合
