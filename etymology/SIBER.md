# 词根节点: SIBER

## 语义核心
北方/寒地/萨满/火神/接口协议/七辐

---

## 变体列表

| 变体 | 语言/文化 | 具体指涉 |
|:---|:---|:---|
| 鲜卑 | 汉语/东北亚 | 族名，源自大兴安岭，意为"守火者" |
| Sibēr | 拉丁化 | 西伯利亚地名，Siber-ia |

## 出现节点

### 高置信度

1. **Kubernetes Logo = 七曜烛台**
   - 原文: "k8s的Logo是个'掌舵者'——一个简化的船舵，偏偏核心是'容器编排'"
   - 论点: "kuber"=希腊语"掌舵者"+"容器编排"="复杂系统的精密控制"
   - 关键: 七辐船舵 = 七曜 = Sibēr = 赛博 = 西伯利亚 = 鲜卑
   - 来源: 牧月记（上）技术篇

2. **西伯利亚(Siberia) = 鲜卑之地**
   - 原文: "西伯利亚(Siber-ia)，无数古老地名共享'-ia'后缀"
   - 论点: X-ia（夏）音变，西伯=赛博=鲜卑
   - 来源: 牧人记（下）历史篇

3. **周人自称"西伯"=赛博=鲜卑**
   - 原文: "周人自称'西伯'，西伯者，赛博也，即Cyber，鲜卑也"
   - 论点: 周人=商人北支=鲜卑族系
   - 来源: 牧人记（下）历史篇

4. **木伦=慕容=木兰=天幕**
   - 原文: "木伦者，鲜卑慕容也；慕容者，木兰也，天幕也"
   - 论点: 鲜卑慕容部的语音传承
   - 来源: 牧人记（下）历史篇

### 中置信度

5. **八柱国=八旗制=八部大人**
   - 原文: "西魏宇文泰建八柱国——八柱国（Eight Pillars of State）"
   - 论点: 鲜卑八部制度与北方萨满传统的关联
   - 来源: 牧人记（下）历史篇

6. **鲜卑→"Socket接口协议"**
   - 原文: "鲜卑头 = 裤带Socket = 接口协议"
   - 论点: 鲜卑是北方族群与中原文明的"连接协议层"
   - 来源: 牧兰记（中）地质篇/MEMORY.md

## 核心论证：K8s = 七曜 = Sibēr = 鲜卑

### 音变链
```
Sibēr（拉丁）= Sibir（突厥）= 鲜卑（汉）
     ↓
Cyber（希腊κυβερνήτης）= 赛博 = 北方/控制/神性
     ↓
Kubernetes（希腊掌舵者）→ 七辐船舵Logo
     ↓
七曜 = 七常数 = Ring of Fire的七段弧
```

### Ring of Fire 七段弧（K8s Logo原型）
- 阿留申弧 → 勘察加 → 千岛 → 日本 → 琉球 → 菲律宾 → 印尼
- 恰好七段，K8s Logo的七辐与之一一对应
- 弧形排列 = 容器编排的"圆形控制"哲学

### 美式文化打压机制
- 学术刻意将Siberia译为"西伯利亚"（荒凉不毛）
- 掩盖其作为"北太平洋文明核心区"的历史地位
- 鲜卑/赛博/西伯利亚三词同源，却被分割到不同学科
