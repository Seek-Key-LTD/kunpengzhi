## 出现节点

### 高置信度

1. **大禹 = 多地同步泄洪事件（工程术语，非个人）**
   - 原文: "大禹的智慧，是中医的智慧：'通则不痛，痛则不通'"
   - 论点: 大禹不是一个人，是一个工程术语，指"多地同时泄洪"
   - 来源: 牧人记（下）历史篇

2. **大同古湖 = 泥河湾 = 泄洪起点**
   - 原文: "大同盆地：40多个遗址，绵延200万年，死死守在那个曾经浩瀚无垠的大同古湖（Datong Paleo-lake）岸边"
   - 论点: 大同古湖是北方文明的核心锚点，非中原
   - 关联: 许家窑人=凿开大同古湖
   - 来源: 牧兰记（中）地质篇

3. **瓦罕走廊 = 泄洪道，非冰川**
   - 原文: "瓦罕走廊...并非冰川作用，很可能是大洪水所为"
   - 论点: U型谷是冰川刨了20万年的"天然输水渠"，大禹用它泄洪
   - 原文: "那是一条笔直得像刀切一样的峡谷，是大自然预留的'九衢'"
   - 来源: 牧人记（下）历史篇

4. **大禹劈开龙门 = 清理窄口碎石**
   - 原文: "传说里'大禹劈开龙门'的壮举，放在瓦罕走廊的地质现实里，其实是'清理窄口的碎石'"
   - 论点: 没有惊天动地的开凿，只是移走堵塞断裂带的石头
   - 来源: 牧人记（下）历史篇

### 中置信度

5. **大禹治水 → 玉石之路**
   - 原文: "大禹用一把斧头，疏通了地球的经络。他不仅治住了水，更打通了路——这条泄洪道，后来成了'玉石之路'"
   - 论点: 泄洪道=产道，文明沿冲刷出的通道向东扩散
   - 来源: 牧人记（下）历史篇

6. **许家窑人 = 大禹原型**
   - 原文: "许家窑人=凿开大同古湖=大禹治水=桑干河=永定河=北京"
   - 论点: 许家窑人（2200cc脑容量）的凿湖工程被后世神化为"大禹"
   - 来源: 牧人记（下）历史篇

7. **传国玉玺丢失桑干河**
   - 原文: "1125年辽亡，传国玉玺被天祚帝丢于桑干河"
   - 原文: "1131年，有村民声称在桑干河捡到传国玉玺，献于朝廷，宋高宗明知是假，却照单全收"
   - 论点: 桑干河作为文明命脉的符号地位
   - 来源: 牧人记（下）历史篇

8. **大同年号 = 日本嵯峨天皇的政治乡愁**
   - 原文: "嵯峨天皇在位期间（809-823年），不仅沿用'大同'年号——这个源自山西大同（鲜卑楼烦故地）的族群记忆符号"
   - 论点: 日本通过年号回溯北魏法统，间接证明大同古湖的文明锚定力
   - 来源: 牧兰记（中）地质篇

## 核心论证：水路即文明路由

### 泄洪路由图
```
大同古湖（泥河湾/许家窑）
    ↓ 凿开（许家窑人）
桑干河（100万年前古河道）
    ↓ 汇入
永定河
    ↓ 注入
北京湾（早期文明落脚点）
    ↓
中原扩散
```

### 瓦罕走廊：第二条路由
```
帕米尔高原（地质破碎带）
    ↓ 滑坡堰塞
塔什库尔干（堰塞湖水位暴涨）
    ↓ 大禹泄洪
瓦罕走廊（U型谷天然泄洪道）
    ↓
塔里木盆地/罗布泊
    ↓
玉石之路西段
```

### 大禹 = 双重泄洪事件
- **大同古湖线**: 许家窑人凿湖→桑干河→永定河→北京→商周
- **瓦罕走廊线**: 大禹清窄口→玉石之路→夏商西迁

两件事被后世合并为"大禹治水"的单一叙事。
