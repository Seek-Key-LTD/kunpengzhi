# KUNLUN — 昆仑 / 克里特 / 复本 / 神圣秩序

> 状态：重构中 | 置信度：高

## 词根本义

**KUNLUN = 复本 / 冠 / 延续 / 神圣秩序的在地投影**

这个音系涵盖了：地理上的神山、生物学的克隆、政治上的王冠、宗教上的木乃伊，是一个语义高度统一的词根。

## 核心论述

### 1. 昆仑 = 克里特 = 奥林匹斯

这三个"神山"不是各自独立的发明。

它们是**同一个原型在不同文明里的投影**：

- 昆仑是原型（Ring of Fire 文明的核心神山）
- 克里特是海上的投影（把山搬到了爱琴海岛屿上）
- 奥林匹斯是克里特的叙事化（给山起了希腊名字）

所以希腊人说"宙斯出生在克里特"——

不是神话，是**地理记忆被翻译成了叙事**。

真实的记忆是：这批人从东方来，带着"昆仑"这个名字，到了克里特，发现那里有个山，就把它叫昆仑。然后后人把它翻译成了宙斯的故事。

### 2. Clone = 木乃伊 = 金缕玉衣

茧 → 蛹 → 蛾 的生物过程：

- 蚕宝宝裹着层层丝 → 茧
- 茧 = 等待重生的容器
- 玉衣 = 人造的茧

所以木乃伊不是"防腐"，是**茧的拟态**——让身体不被破坏，等待有一天"破茧"。

"妈咪/mummy"这个词的来源，不是"妈妈"，是**蚁后**的生物逻辑：
- 蚁后在茧中层层包裹
- 等待合适的时机破茧成为蚁群的母亲
- 人类的"木乃伊 = 等待复活" ← 同理

### 3. Scarab = 屎壳郎 = 昆仑

Scarab（圣甲虫）和"屎壳郎"的发音，在音节结构上完全对应：
- Scar- ≈ 屎壳（拟声+拟形）
- -ab ≈ 螂

这是不可能的巧合——只能证明**这个名字从同一个源头传入了埃及和中国**。

而"克拉"（钻石/宝石重量单位）= 圆球形状 = 粪球 = 圣甲虫滚的粪球。
