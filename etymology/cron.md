## 出现节点

### 高置信度

1. **Scarab = 圣甲虫 = 屎壳郎**
   - 原文: "Scarab...发音是不是就是和屎壳郎三个字也对得严丝合缝？"
   - 论点: Scarab（圣甲虫）与"屎壳郎"在形态/功能上完全对应
   - 来源: 牧人记（下）历史篇

2. **Cron/克隆/克朗/皇冠 同源**
   - 原文: "Cronn/克隆/克朗/皇冠/一元两元"（待查原文精确表述）
   - 论点: 所有带Cr-/Cl-前缀的"圆形/冠/复本"词汇同源
   - 来源: 牧人记（下）历史篇

3. **克里特(Crete) = 昆仑音变**
   - 原文: "克里特岛的米诺斯或者迈锡尼文明...被恶意'退市'了"
   - 原文: "克里=昆仑"（语音对应）
   - 论点: 克里特文明是昆仑文明的地中海节点
   - 来源: 牧人记（下）历史篇

4. **Kremlin = 皇冠之地**
   - 原文: 克里姆林宫（Kremlin）= 皇冠（Kron/Crown）
   - 论点: 俄语Kremlin源自"皇冠"，与克朗/克隆同源
   - 来源: 牧人记（下）历史篇

5. **Cronus = 泰坦神王 = 圆形循环**
   - 原文: Cronus（希腊泰坦）= 时间之神 = 圆形循环
   - 论点: Cron词根掌管时间/王权/圆形三位一体
   - 来源: 牧人记（下）历史篇

6. **黄金阶级 = 蚁后 = 复本的复本**
   - 原文: "亚特兰蒂斯的社会催生出'蚁群式'精密结构：黄金（蚁后Queen）、白银（兵蚁Soldier）、青铜（工蚁Worker）"
   - 论点: 蚁后是唯一繁殖者=复本生产机器=Cron的核心隐喻
   - 来源: 牧兰记（中）地质篇

### 中置信度

7. **蒙古 Altan Uruk = Altantic Uruk**
   - 原文: "Altan Uruk即'Altantic Uruk'（大西洋乌鲁克）"
   - 论点: 蒙古黄金家族命名记忆亚特兰蒂斯/克里特
   - 来源: 牧兰记（中）地质篇

## 核心论证：CRON = 圆形秩序的核心编码

### 音变网络
```
Cron（希腊时间）= Kron（时间圆环）
     ↓
Crown（皇冠/圆形覆盖）= 冠
     ↓
Clone（复制/圆形分裂）= 克隆
     ↓
Krōna（货币/圆形标准）= 克朗
     ↓
Kremlin（皇冠之地）= 克里姆林
     ↓
Kunlun（昆仑/圆形山）= 神圣中心
     ↓
Crete（克里特/环岛）= 地中海昆仑
     ↓
Scarab（圣甲虫/粪球圆形）= 屎壳郎
```

### 蚁群结构 = CRON的生物学原型
- 蚁后（Queen/黄金）= 唯一复制者 = Cron王权
- 兵蚁（Soldier/白银）= 护卫执行 = Cron秩序
- 工蚁（Worker/青铜）= 生产复制 = Cron延续
- 三级结构 = "冠-序-续"的文明模板

### 圣甲虫(Scarab)的宇宙论
- 蜣螂推粪球 = 推动太阳（古埃及宇宙论）
- 粪球=圆=王冠=时间=Cron
- 圣甲虫是Cron神格的生物载体
