## 出现节点

### 高置信度

1. **Yale = 雅鲁 = 藏布江 = 天河**
   - 原文: "雅鲁藏布江 ← 雅绿江 ← 耶鲁大学"
   - 论点: Yale源自雅鲁藏布江的音译（美部商会命名）
   - 藏布 = 象雄 = 文明核心词根
   - 来源: ALI.md/MEMORY.md

2. **雅礼学院 = 阿里 = 天父之道**
   - 原文: "雅礼协会 = 阿里 = 天父之道"
   - 论点: 1901年美国传教士在长沙创办，"雅礼"是Yale的音译，但巧合对应"雅礼"（雅者正也，礼者敬也）
   - 来源: MEMORY.md/ALI.md

3. **阿里巴巴 = 天父/开放之门**
   - 原文: "阿里巴巴 = Al（天）+ Baba（父）= 开放40讲"
   - 论点: "Al-"是闪米特定冠词（=the），"Baba"是父亲，阿里巴巴="天父"的开放版本
   - 来源: ALI.md/牧人记（下）历史篇

4. **Aleut = 雅利特 = 阿留申 = 亚特兰蒂斯**
   - 原文: "阿留申 = Aleutian = 亚特兰蒂斯"
   - 论点: Aleutian Islands是Ring of Fire的南端节点
   - 来源: MEMORY.md/ALI.md

5. **阿里山 = 天山 = 阿里地区**
   - 原文: "西藏阿里地区 = '天的地区'"；"台湾阿里山 = '天山'"
   - 论点: 三处"阿里"共享"天/神圣"语义
   - 来源: ALI.md

6. **阿勒泰 = 金山 = Altai = Altan**
   - 原文: "阿勒泰（Altai）= 金山脉"
   - 论点: Altai/Altan同源，都与"高/金/天"相关
   - 来源: AURUM.md/ALI.md

### 中置信度

7. **Yale作为门锁品牌**
   - 论点: Yale门锁的品牌名可能与耶鲁大学创始人Elihu Yale有关，而非词源
   - 来源: ALI.md（待验证）

8. **阿勒颇(Aleppo) = 雅利安城市名**
   - 论点: Aleppo（大马士革北部古城）是丝绸之路上的雅利安命名城市
   - 来源: ALI.md

## 核心论证：YALE = 天的河流

### 三条YALE路由
```
路由1：藏 → 台 → 天
阿里（藏）= 阿里山（台）= 天山/天父
    ↓
雅鲁藏布江（藏）= 雅绿江（汉）= Yale（英）
    ↓
雅礼协会（中美）= 天父之道

路由2：阿 → 雅 → Aleu → 亚特兰蒂斯
阿留申（Aleutian）= Aleu = 亚特兰蒂斯
    ↓
Ring of Fire 端点

路由3：Al-（闪）→ 阿里巴巴 → 天父
Alibaba = Al（天/定冠词）+ Baba（父）
    ↓
阿拉伯天父叙事
```

### 雅礼协会的深层意涵
- Yale=雅鲁=天河→雅礼=天之礼
- 美国传教士1901年用"雅礼"翻译Yale，恰好命中"雅正+礼敬"的儒家理想
- 巧合还是命名者深谙词源？ASN待验证
