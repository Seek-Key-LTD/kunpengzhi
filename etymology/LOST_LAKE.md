## 出现节点

### 高置信度

1. **大同古湖 = 200万年连续遗址**
   - 原文: "大同盆地：40多个遗址，绵延200万年，死死守在那个曾经浩瀚无垠的大同古湖（Datong Paleo-lake）岸边"
   - 原文: "迄今全世界100万年以上的早期人类文化遗存目前发现53处，大同盆地阳原泥河湾遗址群就占40处，其中马圈沟遗址距今200万年"
   - 论点: 泥河湾是全球密度最高的百万年连续人类遗址群
   - 来源: 牧兰记（中）地质篇

2. **大同古湖 → 桑干河 → 永定河 → 北京**
   - 原文: MEMORY.md: "大同古湖 → 桑干河 → 永定河 → 北京"
   - 原文: "许家窑人=凿开大同古湖=大禹治水=桑干河=永定河=北京"
   - 论点: 大同古湖是北京文明的地理起点
   - 来源: 牧兰记/牧人记

3. **大同古湖 = 水域农业 > 中原农业**
   - 原文: "在大同古湖边，在兴凯湖畔，先民们不需要弯腰插秧。他们站在食物链的顶端，管理着庞大的水下牧场"
   - 论点: 大湖渔猎能量回报率高于大河农业，北方起源说成立
   - 来源: 牧兰记（中）地质篇

4. **悬空寺 = 飞狐陉的空中栈道**
   - 原文: "大同古湖（泥河湾）的存在，让平城周边的陆路时常被季节性洪水淹没，飞狐陉成为唯一可靠通道...悬空寺的雏形，是飞狐陉延伸段的'空中栈道'，是一个试探性的天堑之路"
   - 论点: 悬空寺不是宗教建筑，是工程奇迹的副产品
   - 来源: 牧兰记（中）地质篇

5. **大同古湖 = 第0次分配的北方锚点**
   - 原文: "当鄂霍次克文明的先民们，围着篝火，决定：'你守着大同古湖，管理水下牧场'；'你儿子接着干，别让链条断了'"
   - 论点: 大同古湖是分工体系最早建立的节点之一
   - 来源: 牧兰记（中）地质篇

6. **泥河湾 = 分子人类学的"死刑判决书"**
   - 原文: "西方人不敢看，因为那里埋着他们理论的'死刑判决书'"
   - 论点: 200万年连续地层 vs 分子人类学的"死绝了"假说
   - 来源: 牧兰记（中）地质篇

### 中置信度

7. **北京猿人→田园洞人→山顶洞人 = 同一条磁异常线**
   - 原文: "北京猿人-田园洞人-山顶洞人-完颜亮=同一条磁异常线=风水堪舆=磁场"
   - 论点: 北京西北的遗址链是地质构造决定的
   - 来源: 牧人记（下）历史篇/MEMORY.md

8. **完颜亮 = 北京定都史起点**
   - 原文: "从金代海陵王完颜亮，到元朝郭守敬，再到明代万贵妃的脉络至关重要"
   - 论点: 北京西北郊是权力投射的持续焦点
   - 来源: 牧人记（下）历史篇

## 核心论证：大同古湖 = 北方文明的"零点"

### 地理路由
```
Ring of Fire（北太平洋）
    ↓
鄂霍次克海 → 贝加尔湖 → 兴凯湖
    ↓
大同古湖（泥河湾）← 核心锚点
    ↓ 许家窑人凿湖
桑干河 → 永定河 → 北京湾
    ↓
中原扩散（商周秦汉）
```

### 时间锚定
- 马圈沟遗址: 200万年前
- 40+连续遗址: 200万年不间断
- 大禹治水: 前2070年
- 北魏平城: 398 AD

### 三大文明锚点
| 湖 | 功能 | 遗址密度 |
|:---|:---|:---|
| 贝加尔湖 | 北端中继站 | 高 |
| 大同古湖 | 核心锚点 | 极高（40+遗址） |
| 兴凯湖 | 东端中继 | 中 |
