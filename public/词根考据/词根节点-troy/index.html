    词根节点: TROY#

    语义核心#

    特洛伊/婚飞/联姻政治/木马/婚飞扩散/荷马

    变体列表#

    变体 语言/文化 具体指涉
    Troy/特洛伊 希腊/土耳其 围城战争（特洛伊战争）
    婚飞 生物学 蚂蚁/白蚁的繁殖扩散行为
    木马 汉语/希腊 特洛伊木马/腹中藏兵
    Helen/海伦 希腊语 特洛伊战争导火索
    荷马/Homer 希腊语 吟游诗人/盲诗人
    莲花落 汉语 中国民间说唱艺术

    出现节点#

    高置信度#

    1. 特洛伊 = 婚飞/联姻政治

      • 原文: TROY = 特洛伊/婚飞/联姻政治
      • MEMORY.md: “亚历山大 = … 特洛伊模板 = 婚姻政治”
      • 论点: 特洛伊战争不是为了争夺海伦（美女），而是为了建立政治联姻的婚姻联盟
      • 来源: MEMORY.md/ALEXANDER.md

    2. 婚飞 = 文明的扩散机制

      • 原文: “特洛伊=婚飞/联姻政治”（INDEX.md）
      • 论点: 婚飞（蚂蚁的繁殖扩散）= 文明在地理上的扩散模型
      • 来源: MEMORY.md

    3. 木马 = 腹中藏兵

      • 原文: （推断自希腊神话）
      • 论点: 特洛伊木马的"藏兵"= 文明的内部植入/渗透
      • 来源: 牧人记（下）历史篇

    4. 特洛伊 = 亚历山大的模板

      • MEMORY.md: “亚历山大 = … 特洛伊模板 = 婚姻政治”
      • 论点: 亚历山大东征 = 新的特洛伊战争（婚飞逻辑）
      • 来源: MEMORY.md/ALEXANDER.md

    5. 荷马 = 吟游诗人 = 莲花落

      • 原文: “荷马=吟游诗人=莲花落”（推断）
      • 论点: Homer（荷马）与中国"莲花落"的说唱传统同构
      • 来源: 牧人记（下）历史篇

    中置信度#

    1. 海伦 = 贺楞 = He-llen = 太阳神

      • 论点: Helen = He-len = 太阳神（Helios）+ -en名词化
      • 来源: ALI.md推断

    2. 特洛伊小行星带 = 拉格朗日点

      • 原文: “这些在拉格朗日点的特洛伊小行星带，证明了引力秩序的精巧”
      • 论点: 木星特洛伊小行星 = 宇宙级的"婚飞"（木星轨道上的伴飞群）
      • 来源: 牧月记（上）技术篇

    核心论证：TROY = 婚飞 = 文明的扩散语法#

    婚飞的生物学定义#

    • 婚飞: 有翅繁殖蚁/飞蚁离开蚁群，寻找配偶，建立新群落
    • 过程: 离开→寻找→交配→定居→繁殖
    • 这是蚂蚁文明的核心扩散机制

    特洛伊战争的婚飞解读#

    婚飞生物学:            特洛伊战争:
蚁群(特洛伊)      ←→   斯巴达/希腊
↓飞出寻找配偶         ↓ 抢回海伦
交配/联盟            建立联姻
↓                    ↓
建立新蚁群           特洛伊覆灭
                    ↓
                  希腊人留下（婚飞完成）

    木马 = 文明植入#

    • 希腊人藏在木马中 → 文明的内部植入
    • 攻破城墙不用外力 → 从内部瓦解
    • 这是最古老的"特洛伊木马"协议

    荷马的莲花落#

    • 荷马（盲诗人在各地吟诵史诗）= 中国民间艺人沿街说唱
    • 两者都是"声音的路由"——文明叙事通过吟诵传播
    • 来源: 牧人记（下）历史篇
