词根节点: XIANBEI

语义核心

守火/北人/仙/萨满/拜火教执行层/黄道路由

变体列表

变体语言/文化具体指涉
鲜卑汉语族名，北亚骑马民族
仙汉语山中之人/北方星族
仙北汉语仙之北=大兴安岭
大仙儿岭汉语/东北大兴安岭的民间称呼
夏恩汉语/古称大兴安岭古称，夏=天狼星
Sibēr拉丁化西伯利亚=鲜卑之地
守火汉语/语义鲜卑本义=守护火种
塞北汉语长城以北=鲜卑之地

出现节点

高置信度

  1. 鲜卑 = 守火者 = 拜火教执行层

    • 原文: “鲜卑 = 守火者 = 拜火教执行层”
    • 原文: “鲜，羊+鱼 = 双鱼座→白羊座 = 黄道交界”
    • 原文: “卑，北 = 大兴安岭”
    • 论点: 鲜卑是拜火教（祆教）在北亚的执行系统，不是宗教发明者
    • 来源: 牧兰记/牧人记/MEMORY.md

  2. 《国语》鲜卑条

    • 原文: “《国语》鲜卑条”（待查原文）
    • 论点: 先秦文献已有"鲜卑"记载，非汉人命名
    • 来源: etymology/KUSHA.md 引述

  3. 晋书鲜卑传

    • 原文: “晋书”（待查原文）
    • 论点: 历代正史系统记载鲜卑部落
    • 来源: 牧兰记/KUSHA.md 引述

  4. 鲜卑头 = 裤带Socket = 接口协议

词根节点: XURT

语义核心

许家窑/孔子先祖/板头/脑容量2200cc/凿冰/厌哒

变体列表

变体语言/文化具体指涉
许家窑汉语/地名山西阳原泥河湾遗址群
Xurt音译许家窑的拟国际化名
板头汉语/民俗大同地区"睡扁头"习俗
厌哒/Ephtalite汉语/希腊白匈奴（厌哒=Yāvaghān?）
玉德汉语厌哒=玉德（同音假借）
孔子先祖理论许家窑人是孔子族群基因的源头
2200cc人类学许家窑人脑容量（待验证）

出现节点

高置信度

  1. 许家窑人 = 凿开大同古湖 = 大禹治水

    • 原文: “许家窑人=凿开大同古湖=大禹治水=桑干河=永定河=北京”
    • 论点: 许家窑人（约170万年前）是执行大同古湖泄洪工程的群体，被后世神化为"大禹"
    • 来源: 牧兰记/牧人记/MEMORY.md

  2. 许家窑人脑容量2200cc

    • MEMORY.md: “许家窑人=孔子先祖=2200cc脑容量=睡板头=厌哒=玉德”
    • 论点: 2200cc脑容量超越现代人平均值，可能是智人演化的一个高峰
    • 来源: MEMORY.md

  3. 许家窑 = 板头/睡扁头

    • 原文: “大同地区至今流传的’睡扁头’习俗…那是只有’自己人’才懂的审美”
    • 原文: “与大同地区至今流传的’睡扁头’习俗，在底层逻辑上完全同构——那是只有’自己人’才懂的审美”
    • 论点: 扁头审美是许家窑人后裔的文化标记
    • 来源: 牧兰记（中）地质篇/牧人记（下）历史篇

  4. 厌哒 = 玉德 = 硬/高贵的质感

    • 原文: “在中古音韵和鲜卑文化的语境里，这个连绵词的发音（类似于Iet-dat），隐隐对应着某种’坚硬、高贵’的质感，就像我们说的’玉德’。厌哒=玉德”
    • 论点: 厌哒（Ephtalite/白匈奴）名称与玉德同音，暗示其为掌握玉石/玉文化的族群
    • 来源: 牧人记（下）历史篇

  5. 许家窑 = 孔子先祖

词根节点: YU

语义核心

疏/通/泄洪/工程/水利/大禹

变体列表

变体语言/文化具体指涉
大禹汉语夏禹/神禹，夏朝建立者
禹汉语疏浚、引导（“禹疏九河”）
疏导汉语非堵塞，顺自然之性
Yu英语字母U/泄洪道几何
Wahan瓦罕瓦罕走廊=泄洪咽喉
同/大同汉语大同古湖/大同年号/天下大同
桑干汉语桑干河=大同古湖泄洪道→永定河→北京

出现节点

高置信度

  1. 大禹 = 多地同步泄洪事件（工程术语，非个人）

    • 原文: “大禹的智慧，是中医的智慧：‘通则不痛，痛则不通’”
    • 论点: 大禹不是一个人，是一个工程术语，指"多地同时泄洪"
    • 来源: 牧人记（下）历史篇

  2. 大同古湖 = 泥河湾 = 泄洪起点

    • 原文: “大同盆地：40多个遗址，绵延200万年，死死守在那个曾经浩瀚无垠的大同古湖（Datong Paleo-lake）岸边”
    • 论点: 大同古湖是北方文明的核心锚点，非中原
    • 关联: 许家窑人=凿开大同古湖
    • 来源: 牧兰记（中）地质篇

  3. 瓦罕走廊 = 泄洪道，非冰川

    • 原文: “瓦罕走廊…并非冰川作用，很可能是大洪水所为”
    • 论点: U型谷是冰川刨了20万年的"天然输水渠"，大禹用它泄洪
    • 原文: “那是一条笔直得像刀切一样的峡谷，是大自然预留的’九衢'”
    • 来源: 牧人记（下）历史篇

  4. 大禹劈开龙门 = 清理窄口碎石

    • 原文: “传说里’大禹劈开龙门’的壮举，放在瓦罕走廊的地质现实里，其实是’清理窄口的碎石'”
    • 论点: 没有惊天动地的开凿，只是移走堵塞断裂带的石头
    • 来源: 牧人记（下）历史篇
