# Agentic Network Wiki

## 项目简介

本项目是 **Agentic Network** 的知识库，采用 **Wiki.js + GitLab** 双轨制管理。

### 核心目标

- **知识沉淀**：将分散的信息结构化、体系化
- **协作编辑**：团队成员通过 Git 工作流贡献内容
- **关系图谱**：利用双链语法构建知识网络
- **语义搜索**：未来集成向量搜索，实现智能检索

## 工作流

```
小虾编辑 Markdown → 推送到 GitLab → Wiki.js Import → 显示为页面
```

### 双向同步机制

本项目与 **Wiki.js** 实现了双向同步：

- **Git → Wiki.js**：推送到 GitLab 后，Wiki.js 自动拉取并 Import（默认每分钟同步一次）
- **Wiki.js → Git**：在 Wiki.js 网页上编辑的页面，会自动推送到 GitLab 备份

**注意**：如果一分钟内没有看到更新，请在 Wiki.js 管理后台手动点击 **Import Everything**。

## 内容规范

### 文件格式

所有文档必须包含 YAML frontmatter：

```yaml
---
title: 页面标题
description: 页面描述
published: true
date: 2026-03-08T12:00:00.000Z
tags: [标签1, 标签2]
editor: markdown
dateCreated: 2026-03-08T12:00:00.000Z
---
```

### 双链语法

使用 `[[实体名]]` 创建知识链接：

```markdown
本章分析[[德国]]在[[二战]]前的地缘政治困境。
关键人物包括[[费迪南大公]]和[[俾斯麦]]。
```

```

├── Preface_Pre_WWII.md    # 序言
├── 第一章：... .md         # 章节内容

└── ...
```
