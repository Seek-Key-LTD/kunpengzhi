# 词根节点: XIANBEI

## 语义核心
守火/北人/仙/萨满/拜火教执行层/黄道路由

---

## 变体列表

| 变体 | 语言/文化 | 具体指涉 |
|:---|:---|:---|
| 鲜卑 | 汉语 | 族名，北亚骑马民族 |
| 仙 | 汉语 | 山中之人/北方星族 |
| 仙北 | 汉语 | 仙之北=大兴安岭 |
| 大仙儿岭 | 汉语/东北 | 大兴安岭的民间称呼 |
| 夏恩 | 汉语/古称 | 大兴安岭古称，夏=天狼星 |
| Sibēr | 拉丁化 | 西伯利亚=鲜卑之地 |
| 守火 | 汉语/语义 | 鲜卑本义=守护火种 |
| 塞北 | 汉语 | 长城以北=鲜卑之地 |

---

## 出现节点

### 高置信度

1. **鲜卑 = 守火者 = 拜火教执行层**
   - 原文: "鲜卑 = 守火者 = 拜火教执行层"
   - 原文: "鲜，羊+鱼 = 双鱼座→白羊座 = 黄道交界"
   - 原文: "卑，北 = 大兴安岭"
   - 论点: 鲜卑是拜火教（祆教）在北亚的执行系统，不是宗教发明者
   - 来源: 牧兰记/牧人记/MEMORY.md

2. **《国语》鲜卑条**
   - 原文: "《国语》鲜卑条"（待查原文）
   - 论点: 先秦文献已有"鲜卑"记载，非汉人命名
   - 来源: etymology/KUSHA.md 引述

3. **晋书鲜卑传**
   - 原文: "晋书"（待查原文）
   - 论点: 历代正史系统记载鲜卑部落
   - 来源: 牧兰记/KUSHA.md 引述

4. **鲜卑头 = 裤带Socket = 接口协议**
   - 原文: "鲜卑头 = 裤带Socket = 接口协议"
   - 论点: 鲜卑是北方文明与中原文明的"连接层/协议层"
   - 语义: Socket=物理接口，Protocol=规则层
   - 来源: MEMORY.md

5. **大兴安岭 = 夏恩 = 大仙儿岭 = 夏恩山**
   - 原文: "大兴安岭在历史上最古老的称呼叫做'夏恩'。夏者，热也……恩者，可能是通古斯语的词根"
   - 原文: "这座'夏恩之山'，正是犬与狼图腾的原始发源地"
   - 论点: 夏恩=大兴安岭古称，音变自鲜卑/通古斯语
   - 来源: 牧兰记（中）地质篇

6. **嘎仙洞 = 鲜卑祖庭**
   - 原文: "在大兴安岭北麓，至今保留着鲜卑族的祖庭——嘎仙洞"
   - 原文: "北魏太武帝拓跋焘派人回到大兴安岭祭祖——大马哈鱼的洄游"
   - 论点: 嘎仙洞是鲜卑人种认同的生物学锚点
   - 来源: 牧兰记（中）地质篇

### 中置信度

7. **鲜卑=双鱼→白羊=黄道交界**
   - 原文: "鲜，羊+鱼 = 双鱼座→白羊座 = 黄道交界"
   - 论点: "鲜"字构造暗藏黄道12宫信息，是宇宙秩序在汉字中的投影
   - 来源: MEMORY.md

8. **北魏孝文帝汉化 = 鲜卑基因注入隋唐**
   - 原文: "北魏孝文帝通过'汉化改革'（主动杂交），虽然亡了国，但把鲜卑的基因注入了隋唐的盛世"
   - 论点: 隋唐帝国的"胡气"=鲜卑基因，解释唐朝的世界性
   - 来源: 牧兰记（中）地质篇

9. **拓跋焘=佛狸=Bori（狼）**
   - 原文: "拓跋焘的小名'佛狸'，被辛弃疾误读为庙宇，实则正是阿尔泰语中的'Bori'（狼）"
   - 论点: 狼图腾在鲜卑/蒙古/突厥中的语音传承
   - 来源: 牧兰记（中）地质篇

10. **鲜卑慕容部 = 木兰 = 木伦**
    - 原文: "慕容者，木兰也，天幕也"
    - 原文: "木伦者，鲜卑慕容也"
    - 论点: 慕容部的语音网络与天幕/木兰的关联
    - 来源: 牧人记（下）历史篇

## 核心论证：鲜卑 = 北方火种管理系统

### 拜火教 → 鲜卑执行层
```
亚伯拉罕诸教底层是拜火教 = 北方火种管理
    ↓
拜火教核心：火神圣圣/阿胡拉·马兹达
    ↓
执行层：祭司（火祠）→ 鲜卑（守火者）
    ↓
北亚扩散：萨满（火舞）→ 西伯利亚（寒地守火）
    ↓
回传：摩尼教/明教/景教
```

### 鲜卑的"接口协议"角色
- 北方（Ring of Fire/火山/黄金）→ 中原（青铜/礼制）
- 鲜卑 = 物理层的Socket + 协议层的Router
- 五胡乱华 = 不是入侵，是"路由回传"

### 鲜卑姓氏网络
| 姓氏 | 来源 | 路由方向 |
|:---|:---|:---|
| 尉迟 | 龟兹（Kucha） | 西域→东北→中原 |
| 慕容 | 木兰/天幕 | 北方→中原 |
| 拓跋 | 大兴安岭/狼 | 北方→中原 |
| 宇文 | 通古斯 | 北方→中原 |

**关键洞察**: 胜利者用被征服者的名字——说明路由方向是**从西往东、从北往南**，名字先于人到。
