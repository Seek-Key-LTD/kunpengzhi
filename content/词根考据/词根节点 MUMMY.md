# 词根节点: MUMMY

## 语义核心
木乃伊/妈咪/蚁后/金缕玉衣/茧/沥青/复活/等待

|:---|:---|:---|
| Mummy | 英语 | 木乃伊（古埃及） |
| 妈咪/Mommy | 英语 | 母亲 |
| 木乃伊 | 汉语 | 人工保存的尸体 |
| 蚁后/Queen | 英语/生物学 | 蚁群唯一繁殖者 |
| 金缕玉衣 | 汉语 | 满城汉墓出土/满城金缕玉衣 |
| 茧/Cocoon | 英语 | 蚕蛾幼虫的包覆体 |
| 沥青/Pitch | 英语 | 木乃伊的防腐材料 |

| 妈咪木乃伊 | 流行文化 | Mom/Mummy双关 |

## 出现节点

### 高置信度

1. **Mummy = 蚁后（生物同构）**
   - 原文: "让我们对比蚁后和木乃伊的形态，不难发现Mummy并非人云亦云的沥青，而是实打实的：妈咪"
   - 原文: "妈咪/mummy'这个词的来源，不是'妈妈'，是蚁后的生物逻辑"
   - 论点: Mummy的词源不是"妈妈"（mommy），而是"蚁后"的生物信息
   - 来源: 牧人记（下）历史篇/KUNLUN.md

2. **木乃伊 = 茧的拟态 = 等待复活**
   - 原文: "蚕宝宝裹着层层丝 → 茧 → 所以木乃伊不是'防腐'，是茧的拟态——让身体不被破坏，等待有一天'破茧'"
   - 论点: 木乃伊的本质是"复活协议"，不是防腐技术
   - 来源: KUNLUN.md

3. **金缕玉衣 = 蚕宝宝的仿生学**
   - 原文: "金缕玉衣=蚕宝宝=仿生学=木乃伊=蚁后=妈咪"
   - 论点: 金缕玉衣是汉代贵族用丝/玉模仿蚕茧结构制作的防腐葬服
   - 来源: 牧人记（下）历史篇/KUNLUN.md

4. **蚁后 = 文明的唯一复制者**
   - 原文: "黄金阶级（蚁后Queen）、白银阶级（兵蚁Soldier）、青铜阶级（工蚁Worker）"
   - 论点: 蚁后是亚特兰蒂斯"黄金阶级"的生物学原型
   - 来源: 牧兰记（中）地质篇/CRON.md

5. **沥青 = 雅利安人地区特产**
   - 原文: "沥青=雅利安人地区"（沥青产地的文化标记）
   - 论点: 沥青（制作木乃伊的防腐材料）来自雅利安人活动区
   - 来源: 牧人记（下）历史篇

6. **Mummy = 蚁后的延续逻辑**
   - 原文: "人类的'木乃伊 = 等待复活' ← 同理"
   - 论点: 木乃伊与蚁后共享"保存身体→延续"的逻辑
   - 来源: KUNLUN.md

### 中置信度

7. **华为"狼性文化" = 蚁群逻辑**
   - 原文: "华为所推崇的'狼性文化'，其实质也是高压环境下的集体主义狩猎：像萨满一样敏锐地嗅探信息，像苦行僧一样忍受匮乏，像狼群一样通过压强原则实现对猎物降维打击"
   - 论点: 蚁群/狼群的组织逻辑在现代企业的延伸
   - 来源: 牧兰记（中）地质篇

8. **基布兹/先军政治 = 蚁群模式**
   - 原文: "以色列的基布兹公社，那不就是典型的'战时蚁群'吗？没有私产，按需分配，全民皆兵"
   - 论点: 蚁群结构在不同文明中的反复出现
   - 来源: 牧兰记（中）地质篇

---

## 核心论证：MUMMY = 蚁后的文明隐喻

### 生物学三重复制
```
蚁后: 保存身体 → 持续产卵 → 复制基因
    ↓ 生物拟态
木乃伊: 保存身体 → 等待复活 → 复制灵魂
    ↓ 汉化版本
金缕玉衣: 保存身体 → 玉不朽 → 复制永恒
    ↓ 工业版本
蚕茧: 变态阶段 → 破茧 → 复制形态
```

### Mummy词源新解
- 传统解释: 波斯语mumiya（沥青）→ 木乃伊
- 新解: 蚁后（Queen/Mother）的文明拟态
  - 蚁后=唯一生产者=永生体
  - 木乃伊=模仿蚁后的永生企图

### 金缕玉衣的工程学
- 蚕茧结构: 丝+蛋白质=防水防腐
- 金缕玉衣: 金线+玉片=同构仿生
- 功能: 防止尸体腐烂 = 等待灵魂回归
