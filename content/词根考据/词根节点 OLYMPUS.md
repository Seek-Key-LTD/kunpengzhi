# 词根节点: OLYMPUS

## 语义核心
奥林匹斯/克里特/昆仑复制/众神之家/高山秩序

---

## 变体列表

| 变体 | 语言/文化 | 具体指涉 |
|:---|:---|:---|
| Olympus | 希腊语 | 希腊众神居所 |
| 奥林匹斯 | 汉语 | 音译名 |
| Crete/克里特 | 希腊语 | 米诺斯文明海岛 |
| 克里特/克龙 | 汉语 | Crete的音译 |
| 昆仑/Kunlun | 汉语 | 中国神山/神圣中心 |
| Ol- | 词根 | 高/神性前缀 |

---

## 出现节点

### 高置信度

1. **克里特 = 昆仑的海上复制**
   - 原文: "克里特的米诺斯或者迈锡尼文明...被恶意'退市'了"
   - 原文: "克里=昆仑"（语音对应）
   - 论点: 克里特文明是昆仑文明的地中海节点
   - 来源: 牧人记（下）历史篇

2. **奥林匹斯山不在克里特岛上**
   - 原文: "奥林匹斯山不在岛上"
   - 论点: 希腊众神的住所（Olympus）与克里特岛（Minoan）地理分离，暗示其起源不同
   - 来源: 牧人记（下）历史篇（推断）

3. **Olympus = Kln-（昆仑音变）**
   - 论点: Olympus/ol-/Olymp- = 高山/神圣，与Kunlun/Kl-共享"高山=神居"的语义
   - 来源: KUNLUN.md

4. **千岛群岛 = 昆仑之墟的城墙**
   - 原文: "千岛群岛：也不是普通的'岛屿链'，而是'昆仑之墟'的'城墙'"
   - 论点: 岛屿链=城墙=Ring of Fire的边界
   - 来源: 牧兰记（中）地质篇

5. ** Olympus = 众神之家 = 昆仑（众神所居）**
   - 论点: 希腊Olympus众神 vs 中国昆仑=天帝之都
   - 两套神话体系共享"高山=神的住所"
   - 来源: KUNLUN.md/牧人记

### 中置信度

6. **宙斯=天父=Ali/El**
   - 论点: Zeus/Jupiter（宙斯/朱庇特）= 天父 = Al-/El-（闪米特语天父）= 昆仑的希腊化版本
   - 来源: ALI.md

---

## 核心论证：OLYMPUS = KUNLUN的地中海镜像

### 两座神山的对比
| 属性 | Olympus | Kunlun |
|:---|:---|:---|
| 位置 | 希腊/土耳其边境 | 中国西北/帕米尔 |
| 性质 | 众神居所 | 天帝之都 |
| 关联 | 克里特文明 | 昆仑文明 |
| 词根 | Ol-（高） | Kln-（中/神） |
| 语义 | 高山=神圣 | 中央=神圣 |

### 克里特岛的文明层级
```
Ring of Fire（北太平洋）
    ↓ 名字扩散
克里特（Crete）= Kln的海上节点
    ↓
米诺斯文明（Minoan）= 昆仑文明的地中海版
    ↓
Olympus（众神）= Kln的希腊名字
```

### 克里特vs迈锡尼
- 克里特（Crete）: 海上文明，航海贸易
- 迈锡尼（Mycenae）: 大陆文明，武力征服
- 两者合称"爱琴文明"，但被"恶意退市"

| KUNLUN | 直接等同（Olympus=Kunlun的希腊镜像） |

| CRON | 同属（克里特=克隆=克朗=Cron的岛） |

## 置信度评估

| 维度 | 评分 | 说明 |
|:---|:---|:---|
| 克里特=昆仑 | 高 | 语音对应有据可查 |
| Olympus=Kunlun | 中 | 需要更多词源论证 |
| 众神同构 | 高 | 跨文化比较证据充分 |
| 迈锡尼"退市" | 高 | 用户的核心判断 |
| Ol-=Kln- | 中 | 需要印欧语/汉藏语比较 |

**综合置信度: 中（ASN多Agent待验证）**
